1. O QUE É ESTE PROJETO
--------------------------------------------------------------------------------
UC Brasil é um catálogo digital INFORMATIVO (somente leitura) de Unidades de
Conservação (UCs) do Brasil — federais, estaduais e municipais — com dados
reais e oficiais do CNUC (Cadastro Nacional de Unidades de Conservação, MMA).

D E C I S O E S   T O M A D A S   (NÃO reverter sem conversar com o usuário):
- Escopo ATUAL: catálogo informativo: Home + Busca/Filtros + Ficha da UC + MAPA.
- IMPLEMENTADO: mapa interativo (MapLibre GL) com polígonos reais do CNUC em
  /mapa. Polígonos: shapefile "Polígono CNUC 2025_08" (dados.mma.gov.br),
  convertidos para GeoJSON simplificado em public/ucs_poligonos.geojson (7 MB).
- CORTADO (ainda): dashboard, favoritos, compartilhamento, PWA offline,
  autenticação, multilíngue, comparação.
- CORTADO: banco de dados (PostgreSQL/PostGIS/Redis) e Docker — não há Docker
  instalado na máquina. Os dados vivem em ARQUIVOS JSON: src/data/ucs.json
  (catálogo) e public/ucs_poligonos.geojson (geometrias).
- Stack fixa: Next.js 14 (App Router) + React 18 + TypeScript + Tailwind CSS.
- Deploy alvo: Vercel (gratuito). Sem banco, sem serviços pagos.
- Idioma do código/comentários: português brasileiro. UI em PT-BR.
- Meta: MVP público em 7 dias. MVP + Mapa publicados.

8. OBSERVAÇÕES IMPORTANTES PARA A PRÓXIMA IA
--------------------------------------------------------------------------------
1. O console do Windows mostra acentos "quebrados" em Invoke-WebRequest —
   NÃO é corrupção; os arquivos são UTF-8. Usar o Read/Grep das ferramentas.
2. Não reinstalar maplibre/recharts/workbox/zustand/date-fns sem pedir ao usuário.
3. O arquivo src/data/ucs.json É o banco de dados do MVP. Alterações de dados =
   editar ucs.json ou reexecutar scripts/transform/cnuc-to-json.js.
4. NÃO importar lib/ucs.ts em componentes client (o JSON de 2,3MB iria ao navegador).
   Usar a API (/api/ucs) a partir do client.
5. Servidor de teste na porta 3100 pode estar ativo (PID antigo). Para matar:
   Get-Process -Id <pid> | Stop-Process   (ou procurar node no port 3100).
6. Comentários no código: EVITAR (o AGENTS/opencode pede código sem comentários
   a menos que solicitado). Usar nomes descritivos.
7. Se o usuário pedir algo que contradiga este guia, PERGUNTAR antes de mudar.
8. O MapLibre NÃO cria workers sozinho no bundle do Next: os arquivos
   maplibre-gl-worker.mjs e maplibre-gl-shared.mjs vivem em public/ e o
   setWorkerUrl está no MapView.tsx e no MapViewTI.tsx. Ao ATUALIZAR o
   maplibre, re-copiar os dois arquivos para public/ (senão o mapa para de
   renderizar polígonos).
9. Playwright (devDep) é usado para depurar o mapa em produção com scripts
   .tmp.js na raiz do projeto (ex.: test-*.tmp.js). Apagar esses scripts de
   teste e os .png depois de usar (não devem ser commitados).
10. Debug de produção: expor o mapa com window.__ucMap e consultar
    map.isStyleLoaded(), getSource("ucs").loaded(), queryRenderedFeatures.
    REMOVER o window.__ucMap antes de commitar.
